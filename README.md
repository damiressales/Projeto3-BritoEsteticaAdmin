# Brito Estética Automotiva — Painel Administrativo

Sistema web de gerenciamento interno da **Brito Estética Automotiva**, desenvolvido para o controle operacional de agendamentos, serviços e categorias da plataforma.

## Funcionalidades
- **Controle de Acesso:** Autenticação e gerenciamento de sessão para administradores em PHP.
- **Gestão de Agendamentos:** Visualização, confirmação, atualização de status e cancelamento de horários.
- **Gerenciamento de Serviços e Categorias (CRUD):** Cadastro, edição e exclusão de serviços, valores e descrições exibidos no portal público.
- **Interface Administrativa:** Telas dinâmicas e interativas construídas com TypeScript, HTML5 e CSS3.

## Tecnologias Utilizadas
- **Back-end:** PHP
- **Front-end:** TypeScript, HTML5, CSS3
- **Banco de Dados:** MySQL
